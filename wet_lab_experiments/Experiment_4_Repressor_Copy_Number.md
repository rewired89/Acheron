# Experiment 4: Repressor Copy Number

**Full protocol:** `experiments/BENCH_PROTOCOL_BSUBTILIS.md`, Stage B3.

## The goal, plainly

Count how many actual molecules of each switch-gene's protein exist inside
one cell. This sounds minor, but it decides whether a whole extra backup
circuit (Experiment 7) is even necessary.

The simulations found that if there are only about 1 molecule per cell, cell
division splits things unevenly enough to cause real problems. If there are
5 or more, it's a non-issue. Nobody has measured the real number yet, the
simulations just tested both possibilities.

## What "pass" looks like

Not a pass/fail, a measurement. If the real count comes back comfortably
above 5 per cell, Experiment 7 can likely be dropped from the plan entirely,
saving time and money later.

## Cost and time

Optional. Cheap enough to justify on its own because a good result deletes
a later, more expensive experiment. Not separately quoted.
