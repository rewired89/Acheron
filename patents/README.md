# patents/

What is here, and what is not. The drafts in `drafts_2026/` are drafts: nothing
in this folder has been filed since 2025.

## The 2025 filings are no longer in this folder

The three provisional applications filed with the USPTO in 2025 (Bio-RAID core
system, self-healing recovery, environment-adaptive longevity) were removed from
the working tree on 21 September 2026 at the founder's instruction. They are
superseded: their claims recite a planarian substrate and absolute-voltage-level
encoding, both retired by this project's own simulations.

Two things to know about that removal. Deleting the files does not withdraw
anything from the USPTO, the applications themselves are unaffected and remain
pending. And the text is still in this repository's git history, so "what did we
actually file" remains answerable with `git log` if examination or diligence asks.

## `drafts_2026/`

New drafts matching the project as it stands in September 2026. **Not filed. Not
reviewed by an attorney. No application numbers.** Three subjects:

- `DRAFT_A_DIVISION_INHERITED_MEMORY.md`, the strongest of the three. A genetic
  bistable state that survives destruction of most of the population and is
  restored by cell division during regrowth. This is the one thing the closest
  prior art structurally cannot do.
- `DRAFT_B_DAMAGE_SENSING_REINFORCEMENT.md`, a damage-responsive element that
  transiently reinforces whichever state is currently stored, during regrowth
  only.
- `DRAFT_C_PHASE_REFERENCED_ENCODING.md`, encoding the bit as a phase
  relationship to the colony's own oscillation instead of as a voltage level. The
  most speculative, with the closest prior art. File narrow or not at all.

`PATENTABILITY_ASSESSMENT_2026.md` in that folder says what can be filed, what
cannot, and the three problems that apply to all of it. Read it first.

## The filed Patent 3 subject was dropped

Environment-adaptive longevity prediction is not redrafted. Its numbers are
tuning parameters from a degradation model and its accuracy claim compares a
simulation against itself. There is nothing there to enable.

The GitHub repository is private, so it is not a public disclosure. A posted
preprint is. If it was posted, a US filing has a one year grace period from that
